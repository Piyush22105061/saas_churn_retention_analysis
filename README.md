# SaaS Churn & Retention Analysis

**Author:** Piyush Kumar Jha

## Project Overview

This project investigates customer churn for a Software-as-a-Service (SaaS) business using two independent analytical approaches:

* Cohort Retention Analysis
* Behavioral Churn Predictor Analysis

The objective is not only to identify why customers leave but also to determine which analytical approach provides the most actionable business insights for improving customer retention.
